## En que trabajo

- APIs y servicios con `NestJS`, `Prisma` y `PostgreSQL`.
- Apps web con `React` y `Next.js`.
- Apps mobile con `Expo` y `React Native`.
- Monorepos con `pnpm workspaces` y `Turborepo`.
- Contratos `OpenAPI` + SDKs para integraciones limpias.

## Stack principal

`TypeScript` `Node.js` `NestJS` `Prisma` `PostgreSQL` `React` `Next.js` `Expo` `React Native` `Tailwind CSS` `TanStack Query` `Docker`

## Proyectos que representan bien mi trabajo

- [`portal_saas`](https://github.com/luismasuarez/portal_saas): ecosistema SaaS con API, panel admin y mobile en un mismo monorepo.
- [`portal_cloud`](https://github.com/luismasuarez/portal_cloud): arquitectura con contratos OpenAPI y SDKs para web/mobile.
- [`progesman`](https://github.com/NEXOLIFE-LLC/progesman): plataforma de gestion en Next.js con autenticacion y modulos operativos.
- [`sky-monorepo`](https://github.com/luismasuarez/sky-monorepo): base para microservicios y paquetes compartidos.
- [`dokkap-app`](https://github.com/luismasuarez/dokkap-app): app con Next.js y Prisma enfocada en iteracion rapida de producto.
