* Apps mobile con `Expo` y `React Native`

## 🧠 Filosofía de desarrollo

Me gusta diseñar sistemas donde:

* frontend y backend evolucionen sincronizados,
* los contratos sean la fuente de verdad,
* el código sea reutilizable entre plataformas,
* y la velocidad de desarrollo no destruya mantenibilidad.

Suelo trabajar con:

* arquitectura modular,
* SDD (Spec-Driven Development),
* SDK generation,
* event-driven patterns,
* y workflows orientados a producto real.
